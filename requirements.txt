# Pinned runtime environment for the floor-plan pipeline (main env, Python 3.11).
#
# WHY this file looks the way it does:
#   * Versions are copied from the environment every number in this repo was produced with
#     (env/freeze/main_venv.txt, 2026-10-03). Only packages the code in floorplan/, scripts/ and tests/ actually imports,
#     plus their runtime dependencies, are listed (the dev env also holds evaluation-only and exploration tools).
#   * It is a COMPLETE closure, installed with --no-deps. MoGe declares dependencies we do not use (gradio,
#     flex-gemm = a CUDA build, a training data pipeline) and hloc pulls an unpinned LightGlue; --no-deps keeps
#     those out and keeps the install identical to what was tested.
#   * torch / torchvision are NOT in this file: they come first, from the PyTorch index that matches the machine
#     (cu130 for an NVIDIA GPU, cpu otherwise). See README.md "Setup".
#   * Do NOT add `transformers` to this env: it forces huggingface-hub < 2, which breaks the pinned HF cache layout
#     (docs/ISSUES.md I-002). Anything that needs it gets its own env.
#
# Install (after torch):  uv pip install --no-deps -r requirements.txt
